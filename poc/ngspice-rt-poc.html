ngspice-WASM Echtzeit-PoC

RC-Tiefpass mit extern per JavaScript vorgegebener Sinusspannung. Werte werden pro Zeitschritt textuell ausgegeben.
Voraussetzung: Die Dateien spice-shared.mjs und spice-shared.wasm aus dem GitHub-Action-Artifact müssen neben dieser HTML-Datei liegen (oder Pfad unten anpassen). Diese Seite muss über http(s) geladen werden, nicht per file:// (ES-Module + WASM + Worker). Z.B. im Ordner: python -m http.server und dann http://localhost:8000/ngspice-rt-poc.html öffnen.
